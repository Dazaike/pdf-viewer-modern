# PDF Viewer (modern)

A restyled Chrome PDF Viewer: vertical glass toolbar, hover-peek thumbnails, smooth animations.

## Install
1. Download the zip from [Releases](../../releases/latest) and unzip it.
2. Go to `chrome://extensions`, turn on Developer mode, click **Load unpacked**, pick the folder.
3. Disable any other PDF Viewer extension.

Change the accent color with `--accent` in `content/web/modern.css`.
