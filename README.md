# PDF Viewer (modern)

Restyled build of the Chrome "PDF Viewer" extension (PDF.js, v4.6.130): vertical glass toolbar rail, hover-peek thumbnail sidebar, spring animations, new icon. See [CHANGELOG.md](CHANGELOG.md).

## Install
1. Download `pdf-viewer-modern-v4.6.130.zip` from the Releases page and unzip it.
2. Open `chrome://extensions`, enable Developer mode, choose **Load unpacked** and select the unzipped folder.
3. Disable any store-installed copy of PDF Viewer so only one claims PDFs.

Theme accent: change `--accent` in `content/web/modern.css`.
